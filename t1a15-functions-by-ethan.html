t1a15-mandelbrot-prompt-fred.html Make a single-page full-screen HTML file with minimal inline CSS for a vibrant, zoomable Mandelbrot fractal. Requirements: 1. Use an HTML5 canvas that fills the entire window with a black background. 2. Render the Mandelbrot fractal with smooth, vibrant color cycling that stays vivid as you zoom in deeper. 3. Show a dashed preview rectangle that tracks the mouse cursor, showing the exact region that will fill the screen on the next click. 4. Allow the mouse wheel to dynamically resize the preview box (and zoom scaling factor). 5. Clicking the canvas zooms into the fractal centered on the mouse position using the preview box scale. 6. Add a clickable hint box in the top-left corner that toggles an info modal explaining how the fractal is generated using the formula Z_n+1 = Z_n^2 + C. 7. Use descriptive camelCase JavaScript variables and functions starting with "my", async/await, and direct property assignments (like onclick/onwheel) instead of addEventListener where possible.
